# CafeSystem

CafeSystem — учебная информационная система для автоматизации работы кафе, написанная на PHP.

В системе предусмотрены разные роли пользователей: посетитель, повар, официант, менеджер и администратор.

## Возможности

* регистрация и авторизация пользователей;
* разграничение доступа по ролям;
* просмотр меню и категорий блюд;
* добавление блюд в корзину;
* создание и обработка заказов;
* изменение статусов заказов;
* бронирование столиков;
* управление столиками;
* управление блюдами и категориями;
* просмотр истории заказов;
* административное управление пользователями.

## Используемые технологии

* PHP;
* MySQL;
* PDO;
* Composer;
* `vlucas/phpdotenv`;
* HTML;
* JavaScript.

## Структура проекта

```text
CafeSystem/
├── app/
│   ├── Controlers/     # Контроллеры
│   ├── Middleware/     # Проверка авторизации, ролей и CSRF
│   ├── Repositories/   # Работа с базой данных
│   ├── Services/       # Бизнес-логика
│   ├── Validators/     # Валидация данных
│   ├── Views/          # Страницы приложения
│   ├── core/           # Роутер и вспомогательные классы
│   └── sessions/       # Работа с сессиями
├── database/
│   ├── BD.php          # Подключение к базе данных
│   └── cafe.sql        # SQL-дамп базы данных
├── include/            # Общие элементы страниц
├── public/             # Точка входа и публичные файлы
├── .env                # Настройки окружения
└── composer.json       # PHP-зависимости
```

## Требования

Перед запуском необходимо установить:

* PHP;
* MySQL или MariaDB;
* Composer;
* расширение PHP PDO MySQL.

## Роли пользователей

* **Пользователь** — просмотр меню, создание заказов и бронирование столиков.
* **Повар** — просмотр заказанных блюд и изменение их статусов.
* **Официант** — обслуживание столиков и работа с заказами.
* **Менеджер** — управление меню, заказами, столиками и бронированиями.
* **Администратор** — управление пользователями и доступ ко всем функциям системы.
